================================================================================
ETAPE 1 — PREREQUIS
================================================================================
Installez au préalable :
  - Python 3.11 ou supérieur      (https://www.python.org/downloads/)
  - Node.js 18 LTS ou supérieur   (https://nodejs.org/)
  - Visual Studio Code            (https://code.visualstudio.com/)
  - (Optionnel) MySQL Workbench ou pgAdmin si vous utilisez MySQL/PostgreSQL
    plutôt que SQLite.

Extensions VS Code recommandées :
  - Python (Microsoft)
  - Pylance
  - ES7+ React/Redux/React-Native snippets
  - Prettier - Code formatter


================================================================================
ETAPE 2 — DECOMPRESSION ET OUVERTURE DANS VS CODE
================================================================================
1. Décompressez l'archive project_encheres.zip.
2. Ouvrez le dossier "project_encheres" dans Visual Studio Code
   (Fichier > Ouvrir le dossier...).
3. Ouvrez un terminal intégré : Terminal > Nouveau terminal.


================================================================================
ETAPE 3 — CONFIGURATION ET LANCEMENT DU BACKEND (Django)
================================================================================

3.1. Créer et activer un environnement virtuel Python
--------------------------------------------------------------------------------
Dans le terminal VS Code, à la racine du projet :

  Windows :
    cd backend
    python -m venv venv
    venv\Scripts\activate

  macOS / Linux :
    cd backend
    python3 -m venv venv
    source venv/bin/activate

3.2. Installer les dépendances
--------------------------------------------------------------------------------
    pip install -r ../env/requirements.txt

3.3. Configurer les variables d'environnement
--------------------------------------------------------------------------------
    Copiez le fichier env/.env.example vers backend/.env :

      Windows :  copy ..\env\.env.example .env
      macOS/Linux : cp ../env/.env.example .env

    Par défaut, DB_ENGINE=sqlite : aucune configuration supplémentaire n'est
    nécessaire, une base SQLite locale (db.sqlite3) sera créée automatiquement.

    Pour utiliser MySQL ou PostgreSQL :
      - Changez DB_ENGINE=mysql ou DB_ENGINE=postgresql dans backend/.env
      - Renseignez DB_NAME, DB_USER, DB_PASSWORD, DB_HOST, DB_PORT
      - Décommentez la dépendance correspondante dans env/requirements.txt
        (psycopg2-binary pour PostgreSQL, mysqlclient pour MySQL)
      - Réinstallez : pip install -r ../env/requirements.txt
      - Créez la base au préalable depuis MySQL Workbench / pgAdmin, ou en
        exécutant le script database/schema_and_data.sql

3.4. Appliquer les migrations (création des tables)
--------------------------------------------------------------------------------
    python manage.py makemigrations encheres
    python manage.py migrate

3.5. Créer un administrateur ET des données de démonstration
--------------------------------------------------------------------------------
    Option automatique (recommandée) :
      python manage.py seed_data

    Cela crée automatiquement :
      - Un administrateur     : admin / AdminEncheres2026!
      - Un vendeur de test    : vendeur1 / Vendeur2026!
      - Un acheteur de test   : acheteur1 / Acheteur2026!
      - 6 catégories, plusieurs articles et une enchère de démonstration.

    Option manuelle (facultative) :
      python manage.py createsuperuser

3.6. Lancer le serveur de développement Django
--------------------------------------------------------------------------------
    python manage.py runserver

    L'API est accessible sur :   http://127.0.0.1:8000/api/
    L'interface admin Django :   http://127.0.0.1:8000/admin/


================================================================================
ETAPE 4 — CONFIGURATION ET LANCEMENT DU FRONTEND (React)
================================================================================
Ouvrez un second terminal (gardez le serveur Django actif dans le premier) :

    cd frontend
    npm install

    Copiez le fichier .env.example vers .env (déjà présent dans frontend/) :
      Windows :     copy .env.example .env
      macOS/Linux : cp .env.example .env

    Vérifiez que REACT_APP_API_URL pointe bien vers http://127.0.0.1:8000/api

    Démarrez l'application React :
      npm start

    L'application s'ouvre automatiquement sur : http://localhost:3000


================================================================================
ETAPE 5 — PREMIERE UTILISATION
================================================================================
1. Rendez-vous sur http://localhost:3000
2. Connectez-vous avec un compte de démonstration (vendeur1 / Vendeur2026!)
   ou créez votre propre compte via "S'inscrire".
3. Consultez la liste des articles, filtrez par catégorie/statut.
4. Publiez un nouveau lot via "Publier un lot" (le formulaire valide tous
   les champs : titre, description, prix > 0, dates cohérentes, catégorie).
5. Placez une offre sur un article actif appartenant à un autre utilisateur.
6. Consultez le "Tableau de bord" pour visualiser les statistiques dynamiques
   (courbe d'évolution, répartition par catégorie, taux de conversion...).
7. Gérez les catégories depuis le menu "Catégories" (CRUD complet).


================================================================================
NOTES TECHNIQUES IMPORTANTES
================================================================================
- Authentification : JSON Web Token (access + refresh) via
  djangorestframework-simplejwt. Le jeton d'accès est automatiquement
  rafraîchi côté frontend (voir frontend/src/api/axios.js).

- Validation :
    * Backend : validators Django (MinValueValidator, clean(), validators
      des serializers DRF) pour le prix > 0, la cohérence des dates,
      l'unicité de l'email/nom d'utilisateur, la force du mot de passe.
    * Frontend : validation en temps réel de tous les formulaires
      (React) avant tout envoi au serveur, avec messages d'erreur explicites.

- CORS : autorisé uniquement depuis http://localhost:3000 par défaut
  (modifiable dans backend/.env via CORS_ALLOWED_ORIGINS).

- Statut des articles (EN_ATTENTE / ACTIVE / TERMINEE / ANNULEE) recalculé
  automatiquement selon les dates de début/fin à chaque consultation.

- CRUD complet exposé via l'API REST (préfixe /api/) :
    /api/articles/                (GET, POST)
    /api/articles/{id}/           (GET, PUT, PATCH, DELETE)
    /api/articles/{id}/encherir/  (POST — placer une offre)
    /api/articles/{id}/historique/(GET — historique des offres)
    /api/articles/mes_articles/   (GET — mes propres articles)
    /api/categories/              (GET, POST, PUT, DELETE)
    /api/encheres/                (GET — lecture seule)
    /api/favoris/                 (GET, POST, DELETE)
    /api/dashboard/               (GET — statistiques agrégées)
    /api/auth/inscription/, /api/auth/connexion/, /api/auth/deconnexion/,
    /api/auth/rafraichir/, /api/auth/profil/


================================================================================
DEPANNAGE RAPIDE
================================================================================
- "ModuleNotFoundError: No module named 'django'"
    -> Vérifiez que l'environnement virtuel est bien activé, puis relancez
       pip install -r ../env/requirements.txt

- Erreur CORS dans la console du navigateur
    -> Vérifiez que le backend tourne bien sur le port 8000 et que
       CORS_ALLOWED_ORIGINS contient http://localhost:3000

- "relation/table does not exist" (PostgreSQL/MySQL)
    -> Assurez-vous d'avoir exécuté "python manage.py migrate" après avoir
       créé la base de données vide.

- Page blanche côté React
    -> Vérifiez la console du navigateur (F12) et que REACT_APP_API_URL
       correspond bien à l'URL du backend Django actif.
